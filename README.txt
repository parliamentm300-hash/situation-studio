シチュエーション工房：iPhone/Android向けPWA

【無料公開 GitHub Pages】
1. GitHubにログインし、Publicリポジトリを新規作成します。
2. このZIPを解凍し、中身のファイルをすべてリポジトリ直下にアップロードします（ZIP自体はアップロードしない）。
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
4. Pages欄に表示されるHTTPSのURLをSafariで開きます。
5. iPhoneのSafari共有メニューから「ホーム画面に追加」を選びます。

【注意】
・GitHub Pagesの公開リポジトリのソースは公開されます。個人画像・設定・バックアップはリポジトリにアップロードしないでください。
・登録データは端末内のIndexedDBに保存され、端末間では自動同期しません。
・画像の保存・復元はiPhone実機で未検証です。重要な画像は元データも保管してください。
・バックアップを定期的に書き出してください。
